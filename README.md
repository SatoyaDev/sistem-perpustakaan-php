# 📚 Sistem Pengelolaan Buku Perpustakaan (UTS Backend) Create By. Gede Parama Arya Satya (250030622) - UG253

Aplikasi manajemen perpustakaan berbasis PHP Native (OOP & PDO) dengan arsitektur MVC sederhana dan Bootstrap 5. 

## 🚀 Fitur Utama
- CRUD Data Buku (Tambah, Tampil, Edit, Hapus)
- Upload Gambar Cover Buku (JPG, PNG, WEBP)
- Fitur Pencarian Buku (SQL LIKE Query)
- Validasi Input & Keamanan PDO Prepared Statements
